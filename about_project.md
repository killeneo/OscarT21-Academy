Техническое задание (ТЗ)
Стартап: Платформа поиска, обучения и сертификации тьюторов и социальных работников

1. Описание проекта
Создание цифровой платформы (веб-приложения/сайта) для:
обучения тьюторов и социальных работников;
поиска проверенных специалистов;
сертификации и подтверждения квалификации;
взаимодействия родителей, образовательных центров и специалистов;
развития инклюзивного образования и сопровождения детей.
Платформа объединяет:
образовательную LMS-систему;
маркетплейс специалистов;
систему проверки компетенций и сертификатов;
профессиональное сообщество.
2. Цель проекта
Создать первую современную платформу в регионе, которая:
помогает родителям находить квалифицированных специалистов;
помогает тьюторам получать востребованную профессию;
обеспечивает контроль качества услуг;
формирует профессиональное сообщество специалистов по инклюзии и сопровождению детей.
3. Проблема, которую решает проект
Для родителей:
сложно найти проверенного тьютора;
отсутствует единый реестр специалистов;
нет прозрачной системы оценки компетенций;
высокий риск некачественных услуг.
Для специалистов:
нет современной платформы для обучения и трудоустройства;
отсутствует удобная система продвижения своих услуг;
сложно подтвердить квалификацию;
мало практических программ обучения.
Для рынка:
дефицит подготовленных специалистов;
рост запроса на инклюзивное сопровождение;
отсутствие цифровой экосистемы в сфере тьюторства и социальной поддержки.
4. Целевая аудитория
Основная:
тьюторы;
социальные работники;
специалисты по инклюзии;
педагоги;
психологи;
ассистенты детей с ОВЗ;
студенты педагогических вузов.
Дополнительная:
родители детей;
школы;
детские центры;
инклюзивные хабы;
ННО/фонды;
образовательные организации.
5. Формат продукта
Этап 1 — MVP (минимально жизнеспособный продукт)
Веб-платформа с базовым функционалом:
регистрация пользователей;
каталог специалистов;
онлайн-обучение;
загрузка сертификатов;
личный кабинет;
поиск специалистов;
отзывы и рейтинг.
6. Основной функционал
6.1. Регистрация пользователей
Типы аккаунтов:
специалист;
родитель;
организация;
администратор.
6.2. Личный кабинет специалиста
Функции:
профиль;
фото;
образование;
опыт работы;
сертификаты;
специализация;
стоимость услуг;
календарь занятости;
отзывы;
видеопрезентация.
6.3. Образовательная платформа (LMS)
Функции:
видеоуроки;
вебинары;
тестирование;
домашние задания;
выдача сертификатов;
прогресс обучения;
загрузка авторских курсов.
Контент:
семинары;
тренинги;
курсы по инклюзии;
сенсорная интеграция;
сопровождение детей;
работа с родителями;
soft skills.
6.4. Каталог специалистов
Фильтры:
город;
специализация;
опыт;
рейтинг;
наличие сертификатов;
формат работы (онлайн/офлайн).
6.5. Система подтверждения качества
Функции:
проверка документов;
подтверждение сертификатов;
бейдж “Проверенный специалист”;
рейтинг качества;
система отзывов.
6.6. Поиск и подбор специалиста
Возможности:
умный поиск;
подбор по запросу родителя;
рекомендации;
быстрые заявки.
6.7. Административная панель
Функции:
модерация пользователей;
проверка сертификатов;
аналитика;
управление курсами;
управление платежами;
статистика платформы.
7. Монетизация
Возможные модели дохода:
платные курсы;
подписка PRO для специалистов;
комиссия за заявки;
размещение вакансий;
корпоративные тарифы;
партнерские программы;
гранты и социальные инвестиции.
8. Технологическая часть
Формат:
веб-приложение;
адаптация под мобильные устройства;
дальнейшее масштабирование в мобильное приложение.
Рекомендуемый стек:
Frontend:
React / Next.js
Backend:
Node.js / Python
База данных:
PostgreSQL
Хранение видео:
AWS / Vimeo / Cloud Storage
Авторизация:
Google / Telegram / Email
9. Этапы разработки
Этап 1 — Исследование
анализ рынка;
UX/UI прототип;
описание архитектуры.
Этап 2 — MVP
базовая платформа;
каталог;
LMS;
профили специалистов.
